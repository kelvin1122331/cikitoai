Secangkir kopi, sejuta cerita dari lereng Muria.

Halaman ini bukan bagian dari aplikasi CikitoAI. Ia sengaja dibuat sebagai “website orang lain”: serif, warna kertas, tanpa Tailwind, dan dengan aturan CSS agresif untuk semua button dan div.

Yang perlu diperhatikan: bubble ungu di pojok kanan bawah adalah widget CikitoAI yang ditempel dengan satu baris <script>. Geser, buka, ubah ukurannya — tampilannya tetap utuh karena dirender di dalam Shadow DOM, dan gaya halaman ini sama sekali tidak berubah.

Cara menempelkannya di situsmu

Cukup satu baris sebelum </body>. Tidak ada build step, tidak ada dependensi: 

<script src="/embed/cikito-widget.js" data-theme="auto" defer></script>

Tetap bisa dikendalikan halaman

Widget menyediakan API global. Tombol di bawah ini memanggil CikitoAI.toggle() milik halaman ini sendiri:

Buka / tutup asisten

Lalu apa?

Buka panelnya, pilih “Mode Demo” bila belum punya API key, lalu tekan Jalankan. Untuk jawaban sungguhan, masukkan API key penyedia mana pun — OpenAI, Claude, Gemini, Groq, OpenRouter, DeepSeek, Mistral, xAI, Together, Ollama, LM Studio, atau endpoint kustom.
